# 个人训练服务实现计划

目标：Python + Vue 个人训练服务；按用户后续指示，本次完成本地源码，GitHub 由用户后续提交，部署另行进行。

## 约束与结构

- 使用当前 Python 3.8/FastAPI/Uvicorn 与现有 Vue/Vite 环境，不安装依赖。
- `backend/main.py`：SQLite、密码与会话、模板 CRUD、周历、视频上传播放、记录快照。
- `backend/tests/test_app.py`：权限、模板内动作隔离、任意训练日、历史快照、上传和播放范围。
- `frontend/src/App.vue`：密码访问、周历、模板动作编辑、教学、记录。
- `frontend/src/style.css`：手机/iPad 优先；雾蓝底、海蓝主色、珊瑚色当天标记。周历为视觉主轴。
- 视频由用户提供（3D 或真人）；模板内分别创建动作；训练天数不限；记录保存查看。
- 不上传视频、数据库和依赖目录；固定密码按用户新要求写入后端源码。项目已移至 D:\codex\fitness，与原博客独立。
